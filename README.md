# DNA-sequence-analysis
## 📊 Project Overview

Bioinformatics pipeline for analyzing DNA sequences with focus on:
- GC content calculation
- Nucleotide composition analysis
- Single Nucleotide Polymorphism (SNP) detection
- Mutation rate calculation
- Comparison with reference sequences

**Applications:** Cancer genomics, genetic disease diagnosis, population genetics

---

## 🔬 Analysis Components

### **Part 1: Sequence Statistics**
- Calculates A/T/G/C percentages
- Computes GC content (important for DNA stability & PCR primer design)
- Reports sequence length and composition bias

### **Part 2: Mutation Detection**
- Identifies SNPs by sequence alignment
- Calculates mutation rates
- Compares test sequences against reference
- Determines mutation significance

### **Part 3: Visualization**
- Nucleotide composition bar charts
- GC content comparison plots
- Sequence length distribution
- Mutation rate analysis

## 🎯 Biological Interpretation

**GC Content Significance:**
- High GC content → more stable DNA, resistant to denaturation
- Important for primer design in PCR experiments
- Influences codon usage and gene expression

**Mutation Detection:**
- SNPs can alter protein sequence
- May affect protein function and disease risk
- Critical for cancer diagnosis and prognosis
